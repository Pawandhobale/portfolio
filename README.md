# Pawan Dhobale Portfolio

A premium, modern developer portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Structure

- index.html - Main portfolio page
- css/ - Stylesheets for layout, animation, and responsiveness
- js/ - Interactivity scripts
- assets/ - Images, resume, and other static files

## Features

- Dark premium UI with glassmorphism
- Responsive navigation and layout
- Typing animation in the hero section
- Project, skills, experience, and contact sections
- Lightweight and performance-friendly
